# M Arabia: Water Tanker Custody Transfer Simulator

An interactive 3D simulator and film for the M Arabia automated water tanker system. Switch at any time between the client app, the driver seat, the admin dashboard and the film.

Open `index.html` in Chrome or Edge. It is one self-contained file, and it needs internet for Three.js, Tailwind, the icons and the fonts.

To host it, publish this repository with any static host, such as GitHub Pages, Netlify or Vercel. No build step is needed.

All orders, prices, drivers and readings are demo data.
